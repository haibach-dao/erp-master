# 7. Knowledge base, memory và mind map

Giai đoạn đầu: note, document, tag, liên kết, phân quyền, tìm kiếm full text. Giai đoạn sau: graph relations, vector search và hỏi đáp nội bộ.

Không trộn tri thức cá nhân với tri thức công ty: cần scope `private`, `team`, `company`, `group`.

Nghiệm thu phase đầu: tìm kiếm đúng quyền; note có version và link; mind map có node, edge, kéo thả và liên kết được đến tài liệu/bản ghi nghiệp vụ.
